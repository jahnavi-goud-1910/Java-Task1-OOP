# Task 1 

##  Description
This task is developed in Java to demonstrate the basic concepts of Object-Oriented Programming (OOP). The system manages employee information using classes, objects, inheritance, polymorphism, and encapsulation.

## Objectives
- Understand Java programming fundamentals.
- Implement Object-Oriented Programming concepts.
- Use loops, conditions, and arrays in Java.

## OOP Concepts Used

### 1. Classes and Objects
The `Employee` and `Manager` classes are used to create objects representing employees.

### 2. Encapsulation
Data members are declared as private and accessed using getter and setter methods.

### 3. Inheritance
The `Manager` class inherits properties and methods from the `Employee` class.

### 4. Polymorphism
The `displayInfo()` method is overridden in the `Manager` class.

## Java Concepts Used
- Arrays
- For Loop
- If-Else Conditions
- Constructors
- Method Overriding

- Employee.java


The program displays employee details, salary information, and employee category.
